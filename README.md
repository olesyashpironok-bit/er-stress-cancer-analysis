# ER Stress and UPR Signalling in Cancer

## Project overview

This project explores gene expression patterns associated with endoplasmic reticulum (ER) stress and the unfolded protein response (UPR) in cancer using publicly available transcriptomic datasets.

## Research question

How do UPR-related gene expression patterns differ between cancer and non-cancer samples?

## Genes of interest

- ERN1 (IRE1α)
- EIF2AK3 (PERK)
- ATF6
- HSPA5 (BiP)
- ATF4
- DDIT3 (CHOP)

## Planned methods

- Public transcriptomic data from NCBI GEO
- Data processing using Python and pandas
- Statistical analysis and data visualization
- Biological interpretation of ER stress signalling

## Project status

In progress. Dataset selection and analysis are pending.
